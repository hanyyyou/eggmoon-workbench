# 蛋&月训练营专属工作台

在电脑上打开 WorkBuddy，复制下面这段话发送，即可安装或升级。

> 请从 https://github.com/hanyyyou/eggmoon-workbench/releases/latest/download/story-camp-workbench.zip 下载「蛋&月训练营专属工作台」，按包内《使用说明》帮我安装或原地升级，保留已有资料。遇到问题请先自行排查，帮我打开榜单并确认能看到书名，再按随包说明在我的 WorkBuddy 里设置每天当地上午 9 点更新「社会热点新闻」。已有任务请复用，完成后告诉我下次运行时间。

在工作台里浏览小说榜单、查看作品简介和收藏作品。番茄新书榜可选女频、男频和题材；起点、七猫、飞卢、刺猬猫、晋江及多家海外平台也可切换已收录的榜单。「社会热点新闻」收录婚恋与家庭纠纷报道的原标题、日期和原文链接。

点开书名，在简介下方查看「前 10 章」。番茄和起点可在确认本书离线保存许可后下载开头最多 10 章，断网也能打开：番茄为 HTML，起点为 TXT。刺猬猫和飞卢可点读公开章节，自己的小说 TXT 也能在本机打开。
